# 隐私与数据说明

LumaMark 默认本地优先。书签 URL、标题、站点图标地址、标签、备注、集合、收藏状态、变更版本和回收站记录保存在浏览器本地 IndexedDB；无需注册或登录。

在 Chrome、Edge 和 Firefox 上，LumaMark 使用 `bookmarks` 权限读取和修改浏览器自带的全部书签（书签栏、其他书签、移动设备书签，Firefox 还包括书签菜单和分隔线），用来把它们同步到其他浏览器。书签小程序（`javascript:`）和 `file:` 等非网页链接也会同步，但在 LumaMark 页面里只显示、不直接打开。只有企业策略管理的只读书签不会被读取进同步文件，也不会被修改；Firefox 的 `place:` 动态列表（如“最近添加”）不是书签，同样不同步。浏览器书签同步可以在设置页关闭。

未填写 WebDAV 时不会同步。保存可用的 WebDAV 地址、路径和凭据后会立即检查连接；连通时自动同步默认开启，用户可以关闭，手动同步仍然可用。凭据失败、远端拒绝写入、空间不足或地址不可达会暂停自动同步，并说明是哪一种失败；本地书签保持不变。同步 manifest 只包含书签和文件夹。搜索地址只留在这台浏览器，不进入同步文件。密码保存在本地配置中，不出现在页面文本里。

产品只保存链接及用户编辑的元数据，不保存网页正文、截图、PDF 副本或永久快照。首发不接入 Google/Chrome/Edge/Firefox/Apple 账号同步，不提供 S3、自有服务同步、移动 Safari、团队协作或社交分享。

导出入口位于设置页。卸载或清除扩展前请导出 LumaMark JSON；导出失败不会修改或删除本地数据。

清空回收站后，本地只保留删除标识和时间、版本等元数据，不再存储书签内容或空的占位字段；升级时会自动压缩已有记录。JSON 导出不包含已清空书签的内容或 ID，仍保留尚可恢复的回收站书签。旧版备份中的删除 ID 仍可导入并应用。

WebDAV 同步仅保留已清空书签的去重 ID 列表，用于阻止离线设备把旧书签重新传回；这些 ID 不会按时间自动过期。旧格式的完整墓碑和重复删除记录会在成功同步时清理，后续数据未变化时不会再次上传。

在 Chrome 和 Edge 上，书签库和首页的网站图标来自浏览器本地的图标缓存（`favicon` 权限），不会为显示图标向网站发出请求。Firefox 和 Safari 上没有这个缓存，未保存图标的书签显示字母色块。主题和强调色只保存在这台浏览器。
