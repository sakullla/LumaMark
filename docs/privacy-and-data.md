# 隐私与数据说明

LumaMark 默认本地优先。书签 URL、标题、站点图标地址、标签、备注、集合、收藏状态、变更版本和回收站记录保存在浏览器本地 IndexedDB；无需注册或登录。

只有用户主动配置 WebDAV 并执行同步（或明确启用自动同步）时，LumaMark 才把同步 manifest 发送到用户指定的 WebDAV 地址和路径。凭据保存在浏览器受保护的本地配置中，不显示在页面文本里。网络、认证、只读或空间错误会暂停自动同步并保留本地待同步变更。

产品只保存链接及用户编辑的元数据，不保存网页正文、截图、PDF 副本或永久快照。首发不接入 Google/Chrome/Edge/Firefox/Apple 账号同步，不提供 S3、自有服务同步、移动 Safari、团队协作或社交分享。

导出入口位于设置页。卸载或清除扩展前请导出 LumaMark JSON；导出失败不会修改或删除本地数据。
