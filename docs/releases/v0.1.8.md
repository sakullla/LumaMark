# v0.1.8

清空回收站后，同步文件和导出的备份不再保存已删除书签的正文。

- 永久删除的书签在 WebDAV 同步文件里只保留 id。另一台浏览器仍能认出这些书签已经删过，不会把旧标题、网址和备注传回来。
- 设置页导出的 JSON 同样只记录这些 id。导入时，本地如果还有同一个书签，会清掉正文。回收站里尚未清空的书签仍完整保留。
- 没有书签再指向的已删除文件夹，不再写入导出文件。

两台浏览器都换成这一版后再同步。旧版本读不到这份 id 列表，会把删除记录按原来的体积写回去。

这是常规更新：覆盖原来的解压目录后，在扩展卡片上点击“重新加载”。扩展 ID 不变，无需卸载或重新导入。
