# v0.1.10

改进文件夹选择和书签编辑体验，并适配窄窗口。

- 文件夹选择器改为可折叠的树形结构，可搜索，层级更清楚。
- 编辑书签时，按 Esc、关闭或取消前如果有未保存的修改，会先询问保存还是放弃；切换到其他视图时自动保存。新增 Ctrl/⌘+Enter 保存。
- 窗口较窄时，书签库侧栏改为从左侧滑出的抽屉，文件夹和标签可以正常浏览。
- 修复侧栏文件夹行高度和缩进不一致的问题；选中的文件夹在鼠标悬停时仍保持选中样式。
- 文件夹页顶部的子文件夹与侧栏顺序一致，并显示书签数量；命令面板里各视图的图标与侧栏一致。
- 编辑面板打开时，批量操作栏和提示条以列表区居中；紧凑视图优先完整显示域名。
- 设置页的 WebDAV 密码可以切换显示。

这是常规更新：覆盖原来的解压目录后，在扩展卡片上点击“重新加载”。扩展 ID 不变，无需卸载或重新导入。
