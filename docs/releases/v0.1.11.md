# v0.1.11

新增可自行部署的账号服务和网页书签库，扩展可以登录账号同步书签。

- 新增 Docker 部署的账号服务：每个账号有自己独立的书签库，数据写在挂载的数据目录里，不需要数据库。
- 管理员账号通过环境变量 `LUMAMARK_ADMIN_USERNAME` 和 `LUMAMARK_ADMIN_PASSWORD` 提供。管理员在网页的“账号管理”里创建账号（可生成随机密码）、重置密码、删除账号；网页和扩展都不能自行注册。
- 新增网页书签库：浏览器打开服务地址即可登录整理书签。左侧按收藏、最近、未归类、重复网址、文件夹和标签浏览；新增和修改书签在弹框里完成；支持批量移动、加标签、收藏、删除，删除可撤销，重复网址一键清理，文件夹直接新建、改名、删除；有列表、紧凑、卡片三种视图，支持深浅主题和强调色；刷新页面保持登录。
- 网页导入支持选择 HTML 或 JSON 文件并自动识别格式，导出直接下载文件。
- 扩展可以登录账号：账号里已有书签时，可以选择用账号覆盖本机，或按文件夹名称链和网址把两边合并；可以切换账号，退出前会先写回。
- 网页上保存时如果同一条书签已在别处改过，会列出两边的版本，让你选择保留哪一边或手动合并，选择完成前不会写回账号。
- 未登录时，扩展仍按原来的方式使用 WebDAV。

这是常规更新：覆盖原来的解压目录后，在扩展卡片上点击“重新加载”。扩展 ID 不变，无需卸载或重新导入。部署服务请参考 `docs/installation.md` 的“自己部署的服务”一节。
