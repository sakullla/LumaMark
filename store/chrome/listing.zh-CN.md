# Chrome Web Store 商店文案（简体中文）

## 名称

LumaMark

## 简短说明

本地优先的书签管理器：保存、整理，并通过你自己的 WebDAV 跨浏览器同步。

## 分类

生产力

## 详细说明

LumaMark 帮你保存、整理并同步浏览器书签，同时把数据控制权留给你。

保存与整理：
• 通过工具栏卡片、网页右键菜单或 Alt+Shift+L 保存当前页面。
• 为书签添加标签、备注和文件夹，按标题、网址、标签或备注搜索。
• 使用列表或网格视图、筛选、批量编辑、重复项清理和回收站整理书签。
• 支持撤销操作，以及浏览器 HTML 和 LumaMark JSON 导入导出。

同步与隐私：
• 与 Chrome 自带书签双向同步，不另外复制一套难以管理的浏览器书签。
• 默认只保存在本机，无需注册 LumaMark 账号。
• 只有你主动配置 WebDAV 后，才会把书签同步到你指定的服务。
• 不同步搜索地址，不保存网页正文，不出售数据，不植入广告或分析追踪。

其他特性：
• 不替换新标签页。
• 离线时仍可查看、搜索和整理本地书签。
• 支持浅色、深色和跟随系统主题。

LumaMark 适合想要更清晰的 bookmarks 管理，同时希望使用自己的 WebDAV 服务进行跨浏览器同步的用户。
